# Circuito Digital no Logisim

Projeto acadêmico desenvolvido durante o curso de Ciência da
Computação na UNIFOR, para praticar lógica digital e construção
de circuitos combinacionais.

## Componentes

- Dez entradas identificadas de CH0 a CH9.
- Quatro saídas identificadas como SA, SB, SC e SD.
- Portas lógicas AND, OR e NOT.
- Display de sete segmentos com sinais de a até g.

## Conceitos praticados

- Álgebra booleana.
- Combinação de portas lógicas.
- Representação binária.
- Organização das entradas e saídas.
- Acionamento de display de sete segmentos.

## Ferramenta

O arquivo foi salvo no formato do Logisim clássico 2.7.1.

## Como abrir

1. Baixe o projeto e extraia o ZIP, se necessário.
2. Abra o Logisim.
3. Selecione File → Open.
4. Escolha o arquivo circuito-logico.circ.
5. Abra o circuito main.

## Como explorar

Utilize a ferramenta de interação para alterar as entradas
CH0 a CH9 e observar as saídas SA, SB, SC e SD e os segmentos
do display.

Para verificar o comportamento de cada entrada isoladamente,
mantenha as demais em zero.
